# GV Agile Browser Extension for GitHub

This lightweight browser extension injects the **`⚡ GV Agile`** tab directly into GitHub's repository navigation bar at [`github.com/genvaluelabs-a11y/Genvalue-Labs`](https://github.com/genvaluelabs-a11y/Genvalue-Labs), placing your agile project board right between **Actions** and **Projects**.

---

## 🚀 1-Minute Installation / Reload Guide (Chrome, Brave, Edge)

### First-Time Installation:
1. Open your browser and go to `chrome://extensions` (or `edge://extensions` / `brave://extensions`).
2. Turn **ON** the **Developer mode** toggle in the top-right corner.
3. Click the **Load unpacked** button in the top-left corner.
4. Select the `extension` folder located inside this repository (`Genvalue-Labs/extension`).
5. Open [`https://github.com/genvaluelabs-a11y/Genvalue-Labs`](https://github.com/genvaluelabs-a11y/Genvalue-Labs) in your browser.

### Updating / Reloading After Changes:
Whenever code changes or updates are pulled:
1. Go to `chrome://extensions`.
2. Locate the **GV Agile for GitHub** extension card.
3. Click the **Reload (🔄)** circular arrow button on the card.
4. Verify the version shows **v1.0.2**.
5. Switch to your GitHub tab and hard-refresh (**Cmd + Shift + R** on Mac or **Ctrl + Shift + R** on Windows/Linux).

## 📌 Features
- **In-Repo Tab Navigation**: Seamlessly integrates into GitHub's official repository menu bar (`Code`, `Issues`, `Pull requests`, `Actions`, `⚡ GV Agile`, `Projects`, etc.).
- **Pixel-Perfect Alignment**: Exact baseline alignment and native GitHub UnderlineNav styling matching light and dark themes.
- **Direct Access**: Clicking the tab opens your 7-pipeline **GV Agile** board for GenValue Labs.
- **Fast & Private**: Runs 100% locally with zero external network tracking or third-party dependencies.
