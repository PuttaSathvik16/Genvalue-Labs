# Contributing to Genvalue Labs

Thank you for contributing to Genvalue Labs!

## Pull Request Guidelines

1. **Branching**:
   - Create branches with clear names: `feature/<description>` or `fix/<description>`.
   - Never push directly to `main`.

2. **Commits**:
   - Write clear, concise commit messages summarizing your changes.

3. **Pull Requests**:
   - Ensure your branch is up to date with `main`.
   - Open a PR targeting `main` with a description of what was changed and why.
   - Wait for review before merging.
